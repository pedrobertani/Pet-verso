Este guia reúne textos e respostas sugeridas para preencher as telas do Google Play Console do PetVerso.

## Política de Privacidade

Depois de publicar o projeto na Vercel, use uma URL pública neste formato:

```text
https://SEU-PROJETO.vercel.app/privacidade/
```

A página já está no repositório em:

```text
public/privacidade/index.html
```

### Nome do app

### Descrição curta

```text
Cuide, brinque e evolua com seu pet virtual em um jogo offline e divertido.
```

### Descrição completa

```text
PetVerso é um jogo de pet virtual em português para Android.

Adote um companheiro, cuide das necessidades dele, brinque em minijogos, ganhe moedas, decore os ambientes e acompanhe a evolução do seu pet.

O jogo funciona offline, salva o progresso no próprio dispositivo e não exige cadastro. Você pode cuidar da comida, felicidade, energia, higiene, saúde e inteligência do seu pet, além de ativar lembretes opcionais para não esquecer dos cuidados.

Recursos principais:
- 18 espécies de pets virtuais;
- adoção por escolha ou ovo surpresa;
- cuidados com comida, banho, carinho, sono, limpeza e saúde;
- minijogos para ganhar moedas e aumentar inteligência;
- loja de móveis e personalização de ambientes;
- progresso salvo no dispositivo;
- modo claro e escuro;
- sons, música e notificações opcionais.

PetVerso é uma experiência casual para quem gosta de jogos de cuidado, coleção, decoração e bichinhos virtuais.
```

## Segurança dos dados

### O app coleta ou compartilha dados do usuário?

Para a versão atual, considerando o README do projeto:

```text
Não coleta dados pessoais diretamente pelo app.
```

O progresso do jogo fica salvo localmente no dispositivo.

### Dados salvos localmente

```text
Progresso do pet, moedas, móveis, preferências, tema, som e lembretes ficam armazenados localmente no dispositivo.
```

### Notificações

```text
O app pode solicitar permissão para notificações locais opcionais, usadas somente para lembretes de cuidados do pet.
```

### Dados compartilhados

```text
Não vendemos dados pessoais. Serviços da plataforma Google/Android podem processar dados técnicos necessários para distribuição, segurança e funcionamento do app conforme as políticas do Google.
```

### Exclusão de dados

Como o app não tem conta ou servidor próprio, a exclusão é local:

```text
O usuário pode remover os dados do app apagando os dados do aplicativo nas configurações do Android ou desinstalando o app.
```
